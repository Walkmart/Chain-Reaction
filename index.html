How to Play

  1. Tap keys or type on hardware keyboard. Correct letters turn green and lock.
  2. Each adjacent pair forms one closed-compound word.
  3. 6 tries per word. Hint reveals one correct letter (never the last).
  4. Scoring: +10 per word, −10 per hint, −5 per wrong check, +20 finishing bonus.
  5. One chain per day. Results save if signed in.
